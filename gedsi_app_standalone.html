ລິ້ງນີ້ຖືກຝັງໄວ້ໃນແອັບແລ້ວໂດຍຄ່າເລີ່ມຕົ້ນ — ບໍ່ຈຳເປັນຕ້ອງຕັ້ງຄ່າອີກ. ໃຊ້ຊ່ອງນີ້ພຽງແຕ່ຖ້າຕ້ອງການປ່ຽນໄປໃຊ້ Google Sheet ອື່ນ (ຈະຈື່ໄວ້ສະເພາະ browser ນີ້).
ວິທີຕັ້ງຄ່າ (ເຮັດຄັ້ງດຽວ)
  1. ເປີດ Google Sheet ໃໝ່, ຕັ້ງຊື່ຊີດວ່າ Data ແລ້ວໃສ່ header ຕາມທີ່ລະບຸໃນໄຟລ໌ apps_script_code.gs
  2. ໄປທີ່ເມນູ Extensions → Apps Script
  3. ລຶບໂຄ້ດເດີມອອກ, ວາງໂຄ້ດຈາກໄຟລ໌ apps_script_code.gs ທີ່ Claude ໃຫ້
  4. Deploy → New deployment → ປະເພດ Web app
  5. Execute as: Me  |  Who has access: Anyone
  6. Deploy → ອະນຸຍາດສິດ → ກັອບປີ້ Web app URL ມາວາງຂ້າງເທິງ
